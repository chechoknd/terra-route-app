# MVP Scope

The MVP allows transport companies to:

- login securely
- manage vehicles
- manage drivers
- manage routes
- create trips
- assign drivers and vehicles
- track vehicles in real time
- report incidents
- monitor operations from a dashboard

## Out of Scope

- ticket sales
- payment gateways
- package management
- AI systems
- notifications
- emails
- billing
- invoicing
- analytics engine
- hardware GPS integrations
- geofencing
- maintenance prediction
- chat systems
